Provide `FsusSettingsShell` and `FsusSettingsCategory` for Avalonia navigation, delivering a desktop settings window shell suitable for hosting in a native Avalonia `Window` with a fixed-width vertical category rail, independent scrollable content region with configurable reset/restore offset behavior, optional search slot, fixed action area, Arrow/Home/End keyboard navigation, accessible selection announcements via `AutomationProperties`, and non-modal host singleton window compatibility without FsusUI owning global state.
