Expose the mounted editor session's original document authority through a readonly
public field, with public aliases for its existing ticket and retirement handle.
The session and heavy-feature context share the exact same frozen source object;
capture, private custody and retirement subscriptions retain their original owner,
lifetime, failed-unsubscribe custody and error identity. Missing internal owners
return null. This does not qualify complete host readiness, resources, restoration
or eviction. Source controls remain UNRUN; local source alias only, no publication.
