# FsusUI Design System: The Intellectual Minimalist (高智感极简主义 2026版)

## 1. 核心理念 (Core Philosophy)

FsusUI 2026 版的设计语言被定义为 **"The Intellectual Minimalist" (高智感极简主义)**。这套系统是三种独立设计哲学的精妙融合：

1.  **瑞士排版设计 (Swiss Graphic Design)**: 剥离多余的装饰，高度功能化，依赖严格的数学栅格系统 (Grid)、大面积的宏白空间 (Macro-typography) 和有意的非对称性。
2.  **Ivy Style (低调的奢华 / Low-Key Luxury)**: 散发着一种学院派的“高智商”光环。它避免数字世界浮夸的赛博朋克或霓虹趋势，转而追求经得起时间考验的优雅，界面质感类似于一本装帧精美的高级学术期刊。
3.  **刚中有柔 (Firm Yet Soft)**: 我们拒绝纯粹 0 度直角的绝对冷酷，而是通过注入极度克制的“微圆角”与“描边”，让界面既保持学术严谨的权威感，又兼具人文的亲和力。

我们的最终目标是：创造一个像为知识分子精心策展的高端出版物般的界面——干净、高效、高级且极其易用。

---

## 2. 品牌基因与"标点"元素 (The "Punctuation" Motif)

这套设计系统从品牌核心 Logo (`Fsu's Blog.`) 中提取了一个关键设计元素：**标点符号（The Punctuation Mark）**。

- **排版级的句号**: Logo 末尾那个粗犷黑色字体旁的微小灰色圆点 (`.`) 被升格为核心的 UI 骨架。
- **如何应用**: 这个极简的圆点可以作为列表的无序符号 (Bullets)、作为大标题末尾的极简装饰锚点，或是作为极其干练的 Loading 动画。它为整个系统定下了“学术与编辑”基调。

---

## 3. 字体排版体系: 现代学者 (The Modern Scholar)

在 FsusUI 中，排版 (Typography) 是绝对的主角，它承担了瑞士风格的重量以及现代科技的友好感。

- **西文与数字 (Primary Typeface)**: **Google Sans**。它提供了出色的几何清晰度和可读性，带有轻微友好的科技感边缘。
- **中日韩字体 (CJK Typeface)**: **Noto Sans CJK**。完美补充 Google Sans，确保多语言混排下的绝对平衡、和谐与高辨识度。
- **层级与布局规则**:
  - 拥抱 **Swiss approach**: 强制使用左对齐 (Flush-left / ragged right)，抛弃两端对齐。
  - **禁止滥用居中**: 除非在组件内部具有极强的结构必要性（如模态框顶部居中标题），禁止将大段文本居中。
  - **戏剧化的排版对比 (Dramatic Contrast)**: 将巨大、粗体的 Google Sans 大标题与极小、但结构极其严密的次级信息搭配在一起。

## 4. 色彩与表面哲学: 墨、纸、笔 (Ink, Paper, and Pen)

调色板彻底抛弃了刺眼的纯数字 HEX 颜色，转向极具物理质感的豪华编辑材料。同时，为了保证完美的交互体验，我们极为克制地引入了一种强调色。

### 核心调色板

- **核心黑 (The Ink | 墨)**: `#0F0F11` (极深的微暖黑色)。
  - _应用_: 所有主要文本、品牌 Logo 以及强力 CTA（主要）按钮。质感犹如高质量的打印油墨。
- **核心白 (The Paper | 纸)**: `#FCFCFC` 或 `#F7F7F8`。
  - _应用_: 用于主背景和容器填充。这是一种非常微妙的暖灰白中性色，用来模拟高级书写纸张，不仅缓解视觉疲劳，更是营造 "Ivy Style" 奢华感的关键。
- **品牌灰 (The Dot | 点)**: `#A1A1AA` 或 `#8E8E93`。
  - _应用_: 直接从 Logo 的句点提取。用于次要文本、极其微妙的边框线以及未激活/禁用状态。

### 点睛色

- **强调色 (The Fountain Pen | 钢笔)**: **`#2A599C` (Scholarly Blue 学术蓝)**。
  - _应用_: 为了确保无障碍访问 (Accessibility) 和明确的交互反馈，我们引入了这种让人联想到经典钢笔墨水的低饱和深蓝色。它绝不喧宾夺主，完美契合学院派审美。**严格限制仅用于功能性 UX 反馈**（例如：文本链接、激活的 Tab 标签、Input 焦点环 Focus Rings，以及部分按钮的 Hover 状态）。

## 5. 空间与几何: “刚中有柔” (Firm Yet Soft 2026)

界面的结构完整性必须像坚硬的瑞士网格一样不可动摇，但触觉与微观层面的执行必须显得充满人情味。

### 5.1 现代圆角体系 (Radii Evolution)

2026 版本打破了过度粗犷的设计，引入了具有现代有机构成感的圆角阶梯：

- **微控件 (`8px` / `6px`)**: 输入框、按钮、Checkbox 等微型控件，采用极其舒适的微圆角，消解锐利感。
- **浮动面板 (`24px`)**: 所有承载大面积内容的浮动容器（Dialog、Card、Drawer、Popover 等）强制采用 `24px` 的大圆角，配合极简排版，带来平滑的视觉动线。
- **有机胶囊 (`999px`)**: 对于 Badge 或非常特殊的交互锚点，依然保留了纯圆形的胶囊几何，以保持活力。

### 5.2 深度与材质: 微阴影与毛玻璃 (Depth & Glassmorphism)

我们严禁使用廉价的重色投影，代之以现代的通透质感：

1.  **高级毛玻璃 (Frosted Glass)**: 所有浮动悬层（Dialog, Drawer, Select Dropdown）均强制使用高强度的背景模糊 (`backdrop-filter: blur(40px) saturate(120%)`) 与极弱的半透明白底 (`rgba(255, 255, 255, 0.75)`)。如同高端磨砂玻璃压在页面上。
2.  **多层级微阴影 (Micro-Shadows)**: 不再是黑灰色的死气投影，而是拥有巨大扩散范围和低透明度的环境光投影（如 `0 32px 64px rgba(0, 0, 0, 0.08)`），并且顶部永远搭配一条极其锐利的纯白内反光 (`inset 0 1px 0 rgba(255, 255, 255, 0.8)`)，营造极致的雕塑感。

## 6. 核心组件实施规范

### Button (按钮)

- **Primary**: 纯色 "Ink Black" (`#0F0F11`)，搭配白色文字。无边框。
- **Secondary/Ghost**: 透明背景，极细的 1px 灰色边框，文字为 Ink Black。
- **交互态 (Hover/Focus)**: 悬停时，Primary 会从黑转为 **Scholarly Blue (`#2A599C`)**，同时通过微投影轻微抬起。文本链接和次级按钮会在悬停时变色，提供克制且高级的视觉反馈。

### Input Fields & Controls (表单与输入)

- **默认态**: 保持建筑般的硬朗，`8px` 圆角，搭配稳重的 1px 边框 (`#E4E4E7`)。
- **激活态 (Focus)**: 当用户交互时，原生的浏览器外发光被彻底禁用，替换为一条极其干脆利落的 1px **Scholarly Blue (`#2A599C`)** 内描边 (Focus Ring)。

### Dialog & Drawer (弹窗与抽屉)

- **背景遮罩 (Overlay)**: 去除原本沉闷的黑纱，使用通透的毛玻璃层 (`blur(16px)` + `rgba(252, 252, 252, 0.5)`)。
- **容器结构**: 内侧包含 24px 大圆角与毛玻璃本身，所有原本默认挤压内部排版的冗余 padding 将被释放。右上角关闭按钮将与标题严丝合缝地对齐于边缘。

### Iconography (图标系统 - SVG)

- **描边消解 (Stroke Rounding)**: 所有 SVG 图标（不仅是 element-icons，包含全站 svg）必须全局强制继承 `stroke-linejoin="round"` 与 `stroke-linecap="round"`，并且通过极其微弱的 `stroke-width` 进行补帧。这能让所有的冷酷实心几何体瞬间呈现出如钢笔墨水洇开般的高级微圆角边缘。

## 7. “做与不做”清单 (Do's and Don'ts)

### 🟢 Do (必须遵守):

- **Do** 严格让所有元素对齐于不可见的数学栅格。瑞士排版法则不可亵渎。
- **Do** 只能将 **Google Sans** 和 **Noto Sans CJK** 搭配使用，不得引入第三方毫无根据的字体（如 Comic Sans 或 Arial）。
- **Do** 克制地使用 **Scholarly Blue** 强调色来引导用户的视觉落点。让 UX 像 UI 一样充满智慧。
- **Do** 极其激进地使用留白 (Whitespace)，不要害怕屏幕上的空，空即是奢华，空即是专注。

### 🔴 Don't (严厉禁止):

- **Don't** 使用高饱和度、荧光色、渐变霓虹灯等“数字廉价感”色彩。点缀色必须保持学术和克制。
- **Don't** 过度设计。如果一个边框线或底纹阴影不能起到明确结构层级或强化交互的作用，立刻删除它。让字体本身成为建筑。
- **Don't** 使用粗糙、生硬的原生浏览器组件默认蓝圈，永远使用系统提供的 Focus Rings 处理。
