# 国际化

FsusUI 组件默认使用**中文**。如需切换其他语言，参考以下配置。

---

## 全局配置

在注册 FsusUI 时通过 `locale` 选项配置语言：

```ts
// main.ts
import ElementPlus from 'element-plus'
import zhCn from 'element-plus/es/locale/lang/zh-cn'

app.use(ElementPlus, {
  locale: zhCn,
})
```

## 通过 ConfigProvider

也可以使用 `ElConfigProvider` 组件在应用层级配置语言：

```vue
<!-- App.vue -->
<template>
  <el-config-provider :locale="locale">
    <app />
  </el-config-provider>
</template>

<script setup lang="ts">
import { ElConfigProvider } from 'element-plus'
import zhCn from 'element-plus/es/locale/lang/zh-cn'

const locale = zhCn
</script>
```

---

## 日期与时间本地化

FsusUI 内部使用 [Day.js](https://day.js.org/) 管理 `DatePicker`、`TimePicker` 等组件的日期。需要单独导入 Day.js 语言包：

```ts
import 'dayjs/locale/zh-cn'
```

> **FsusUI 特有**：FsusUI 从主入口额外导出了 `dayjs`，可直接通过 `import { dayjs } from 'element-plus'` 使用，无需单独安装。

| 语言 | 代码 |
|------|------|

| 繁体中文 | `zh-tw` |
| 英文 | `en` |
| 日文 | `ja` |
| 韩文 | `ko` |
| 法文 | `fr` |
| 德文 | `de` |
| 俄文 | `ru` |
| 西班牙文 | `es` |
| 阿拉伯文 | `ar` |
| 葡萄牙文 | `pt` |
| 意大利文 | `it` |
| 越南文 | `vi` |
| 泰文 | `th` |
| 印尼文 | `id` |
| … | 共 50+ 种 |

完整语言列表见 [`packages/locale/lang/`](../../packages/locale/)。
