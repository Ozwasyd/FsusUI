# Internationalization

FsusUI components default to Chinese. Configure another locale at install time
or on the root `ConfigProvider`.

## Global configuration

```ts
// main.ts
import ElementPlus from '@ozwasyd/element-plus'
import zhCn from '@ozwasyd/element-plus/es/locale/lang/zh-cn'

app.use(ElementPlus, {
  locale: zhCn,
})
```

## ConfigProvider

Use `ElConfigProvider` to set the locale at the application level:

```vue
<!-- App.vue -->
<template>
  <el-config-provider :locale="locale">
    <app />
  </el-config-provider>
</template>

<script setup lang="ts">
import { ElConfigProvider } from '@ozwasyd/element-plus'
import zhCn from '@ozwasyd/element-plus/es/locale/lang/zh-cn'

const locale = zhCn
</script>
```

## Date and time localization

FsusUI uses [Day.js](https://day.js.org/) for dates in components such as
`DatePicker` and `TimePicker`. Import the matching Day.js locale separately:

```ts
import 'dayjs/locale/zh-cn'
```

FsusUI also exports `dayjs` from the main entry (`import { dayjs } from
'@ozwasyd/element-plus'`), so no separate Day.js install is needed.

`vue/packages/locale/lang/`:

| --- | --- |
| Simplified Chinese | `zh-cn` |
| Traditional Chinese | `zh-tw` |
| English | `en` |
| Japanese | `ja` |
| Korean | `ko` |
| French | `fr` |
| German | `de` |
| Russian | `ru` |

| Arabic | `ar` |
| Portuguese | `pt` |

| Vietnamese | `vi` |

See [`vue/packages/locale/lang/`](../../vue/packages/locale/) for the complete
list.
