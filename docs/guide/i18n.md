# Internationalization

FsusUI 2.0 ships built-in `zhCN` (Simplified Chinese, default) and `en`
(English) locales plus `defineFsusLocale()` for zero-bloat custom languages.

## Global configuration

```ts
import FsusUI from '@ozwasyd/fsusui'
import { en, zhCN } from '@ozwasyd/fsusui/locale'

app.use(FsusUI, {
  locale: zhCN,
})
```

## ConfigProvider

```vue
<template>
  <FsusConfigProvider :locale="en">
    <App />
  </FsusConfigProvider>
</template>

<script setup lang="ts">
import { FsusConfigProvider } from '@ozwasyd/fsusui'
import { en } from '@ozwasyd/fsusui/locale'
</script>
```

## Custom locales

Extend an existing locale cleanly using `defineFsusLocale`:

```ts
import { defineFsusLocale, en } from '@ozwasyd/fsusui/locale'

export const jaJP = defineFsusLocale({
  ...en,
  name: 'ja-JP',
  common: {
    ...en.common,
    confirm: '確認',
    cancel: 'キャンセル',
  },
})
```

## Date and time localization

FsusUI 2.0 replaces `dayjs` with a zero-dependency native `Date` +
`Intl.DateTimeFormat` engine that follows the active locale's BCP-47 tag
automatically.
