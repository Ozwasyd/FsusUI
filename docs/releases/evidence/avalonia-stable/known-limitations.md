# Known limitations

## Known limitations

No approved stable component family is missing from the baseline gallery,
documentation, package audit, or public API validation.

Deferred work is limited to complex components documented in
`docs/avalonia/complex-components-roadmap.md`, such as terminal, file manager,
log viewer, markdown viewer/editor extensions, and code block work. These are
outside the approved stable scope and must not be described as stable package
coverage until their contracts, budgets, accessibility evidence, and platform
overrides are complete.
