# Archived Package Registry Workflow

This directory keeps the retired branch-push GitHub Packages workflow for
historical reference only. Files here are outside `.github/workflows/`, so
GitHub Actions will not execute them.

The active release path is `.github/workflows/publish-npm.yml`, which publishes
tag-triggered, quality-gated immutable candidates of `@ozwasyd/element-plus` to
GitHub Packages (`https://npm.pkg.github.com/`).
