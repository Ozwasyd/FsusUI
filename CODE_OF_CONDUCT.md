# Code Of Conduct

FsusUI uses a small public-preview conduct policy.

## Expected Behavior

- Be respectful and direct.
- Keep technical critique focused on code, docs, behavior, and evidence.
- Provide enough reproduction detail for maintainers to evaluate a report.
- Respect maintainer decisions on API stability, security disclosure, and
  release timing.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private security details outside the security reporting process.
- Posting private user data, customer screenshots, tokens, or internal paths.
- Repeated off-topic comments that block issue or pull request triage.

## Enforcement

Maintainers may edit, hide, or remove comments, close issues, restrict
participation, or block users when behavior harms the project or exposes
private/security-sensitive information.

Security reports must follow [`SECURITY.md`](./SECURITY.md), not public issues.
