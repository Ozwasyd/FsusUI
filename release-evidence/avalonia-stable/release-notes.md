# Release notes

## Release notes for stable consumers

Stable consumers receive three coordinated Avalonia packages:

- `FsusUI.Avalonia` for controls, overlay infrastructure, locale provider,
  product primitive families, text viewer/editor, data tables, virtualization,
  and tree primitives.
- `FsusUI.Avalonia.Themes` for light/dark, density, high-contrast, motion, and
  runtime theme management.
- `FsusUI.Avalonia.Icons` for generated stable icon keys and resources.

The stable scope is governed by public API baselines, visual and accessibility
conformance, performance budgets, package content audits, and a packed consumer
install smoke test.

Known limitations are documented in [known limitations](known-limitations.md)
and do not exclude any stable baseline component family.
